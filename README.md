# Planora

Planora is an event-planning application designed to make organizing events easier and less stressful. Users can plan weddings, birthdays, graduations, baby showers, corporate events, and more.

The application will include budgeting, expense tracking, guest lists, RSVP tracking, vendor management, checklists, schedules, deadlines, and reminders.

## Project Purpose

The purpose of Planora is to bring the most important parts of event planning into one organized platform. Instead of using multiple apps, spreadsheets, notes, and group chats, users can manage their event in one place.
